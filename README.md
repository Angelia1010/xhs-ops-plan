## 三、共性问题（按影响排序）

1. **发得太密，自己分流**：5 天 8 篇游戏笔记，两次半小时内连发 2–3 篇。
2. **标题两极分化**：有情绪有结果的标题有效；「今日小雪」「请你吃火锅呀」「来玩个小游戏」没钩子或像广告；普遍缺少可被搜索的关键词（文物修复游戏、火锅人格测试、转运手串）。
3. **封面风格不统一**：古风插画、深蓝金字、实拍手串、科技风深色截图混用，主页无辨识度；封面点击率环比 -43%。
4. **没有行动引导**：几乎不提"点下方小工具"或"评论区晒结果"，收藏评论普遍为 0。
5. **笔记不是游戏的主要流量来源**：322 对 110、97 对 23、62 对 15，流量多半来自平台小工具分发。
6. **视频开头留不住人**：完播率 14%；但火锅视频拿到 142，视频可做，问题在前 3 秒。

待确认：每篇笔记是否挂载了小工具（发布页 → 添加组件 → 小工具）。

## 四、执行计划

### 原则
- 一天最多 1 篇，19:30–21:00 发；同一游戏两篇至少间隔 3 天。
- 三个游戏轮推：文物修复室、火锅局、手串 + 运气；拾羽小院、消消乐暂停推广。
- 格式按内容定：有过程有动作的（拆福袋、涮火锅）做视频，前 3 秒直接放结果；有结果有对比的（修复前后、运势卡、人格卡）做 3–6 张图文轮播。
- 每篇必备：游戏结果图做封面、一个可搜索关键词、"点下方小工具"、一个评论区互动问题。
- 统一封面模板：米白/奶油底，左上角固定"辉夜妖姬的小游戏"标签，中间结果图，上方一行 ≤12 字大字钩子。
